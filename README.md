# HyperHLE

HyperHLE is an independent fork of [touchHLE](https://github.com/touchHLE/touchHLE), a high-level emulator for early iPhone OS applications.

## Status

This project is experimental and compatibility varies by application. It currently targets the original 32-bit iPhone OS application environment. The bundled Dynarmic CPU backend is built with both ARM32 (`A32`) and ARM64 (`A64`) frontends by default; enabling a frontend does not by itself add a complete 64-bit guest runtime.

See the project documentation and issue tracker for supported applications, known limitations, and build instructions.
